# Security Policy — gthgomez (profile repository)

## What this repository is

This is a public profile repository. It contains a [README](README.md) and a [LICENSE](LICENSE) and no runnable product code, no backend, and no user data. There is no service here to attack and nothing to breach.

The [LICENSE](LICENSE) is a proprietary license notice. The source is published for source visibility and transparency only, and no permission is granted to copy, modify, redistribute, or build derivative works.

## Project status: proprietary, not open source

Because no permission to use the code has been granted, a defect in it is not a "vulnerability" in the open-source sense. There is also nothing in this repository to defect. The owner maintains separate products and separate open-source projects, each with its own documentation; none of them are governed by this file.

## What this repository does not offer

- **No security support.** The maintainer does not triage, investigate, or remediate security reports against this profile repository.
- **No coordinated disclosure program.** There is no embargo, no safe harbor, and no private disclosure window.
- **No bug bounty.** No reward is offered.
- **No response-time commitment.** There is no SLA and no support window.
- **No supported versions.** There are no releases and no supported versions.

## Reporting a genuine concern

Do not open a public issue against this repository. If you believe you have found a genuine security concern:

- If it concerns a specific product, find that product's own repository and use GitHub's private vulnerability reporting there (**Security** tab → **Report a vulnerability**), if it is available to you. Each product is documented on its own terms, not here.
- Otherwise contact the repository owner through their public profile at <https://github.com/gthgomez>.
- Do not include working exploit code, credentials, or third-party personal data in a public report.
- You receive no service commitment, no bounty, and no assurance of a fix or of any response.

## Visibility is not permission

The repository being public creates no support obligation. Publishing source does not grant a license, does not create a support contract, and does not make the maintainer a vendor to you. Opening an issue or submitting a pull request grants you no rights and creates no partnership; contributions are not accepted for reuse, and no license is granted over anything you send here.
